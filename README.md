# 새록

AI 기반 기억력 증진 및 생활 관리 서비스 **새록**(구 기억온)의 앱 디자인 시안입니다. 팀 휴즈니스.

- `새록_앱데모_1차.html`, `새록_앱데모_2차.html`: 브라우저에서 바로 여는 모바일 앱 데모
- `새록_2차_디자인_산출물/`: 사용자 흐름, 정보 구조, 와이어프레임, UI/UX 포트폴리오, 화면 32장
- `app_design_20261030/`, `app_design_20261102/`: 1차·2차 시안 이미지와 참고 자료
- `build/`: 데모와 디자인 보드를 만든 스크립트

`새록_2차_디자인_산출물/` 이미지는 새록 이름으로 다시 렌더링했습니다. `app_design_20261030/`, `app_design_20261102/`의 이전 시안 이미지에는 예전 이름(기억온)이 남아 있습니다.
